# 01. Chuẩn bị môi trường thực tập

## 1. Mục tiêu

Chuẩn bị các công cụ cần thiết phục vụ quá trình
học tập và thực hành lập trình.

## 2. Công cụ sử dụng

### Visual Studio Code

- Công cụ soạn thảo mã nguồn.
- Hỗ trợ HTML, Markdown và nhiều ngôn ngữ lập trình.
- Tích hợp Terminal và Git.
- Trang chủ: https://code.visualstudio.com/

### Git

- Hệ thống quản lý phiên bản phân tán.
- Theo dõi lịch sử thay đổi của mã nguồn.
- Hỗ trợ quản lý và đồng bộ mã nguồn với GitHub.
- Trang chủ: https://git-scm.com/

## 3. Kiểm tra cài đặt
