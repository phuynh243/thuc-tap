# 03. Markdown

## 1. Mục tiêu

- Hiểu khái niệm Markdown.
- Nắm được các cú pháp cơ bản.
- Sử dụng Markdown để viết tài liệu kỹ thuật.
- Áp dụng Markdown vào báo cáo thực tập.

## 2. Tài liệu tham khảo

- [Markdown Guide](https://www.markdownguide.org/)
- [Markdown Tutorial](https://commonmark.org/help/tutorial/)

## 3. Thực hành cú pháp Markdown
